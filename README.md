# Password Generator (passwordGene)

Generador de contraseñas seguras en Python.

Características

- Permite elegir la longitud.
- Permite incluir mayúsculas, números y caracteres especiales.
- Usa generación segura con `secrets`.

Cómo ejecutar

```bash
python -m src.password_generator
```

Ejemplo de uso

```
Introduce la longitud de la contraseña: 12
¿Usar letras mayúsculas? (s/n): s
¿Usar números? (s/n): s
¿Usar caracteres especiales? (s/n): s

Contraseña generada: A9$dF2!kLm8Q
```

Tecnologías

- Python 3.8+

Archivo principal: `src/password_generator.py`
